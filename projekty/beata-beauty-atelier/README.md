# BEATA BEAUTY ATELIER

Komplet plikow strony zapisany w katalogu `site/`, odtworzony z paczki ZIP uzytej przez Vercel. SHA256 paczki zweryfikowane: `16760ed44f555afb96c70b3b8af5736d498b4383d6abdd45cf5b7fbf3582b67a`.

Pliki `build.mjs` i `package.json` sa zachowana konfiguracja budowania. Strona stanowi wersje demonstracyjna Zielonej Marki, bez potwierdzenia relacji z rzeczywista firma.
