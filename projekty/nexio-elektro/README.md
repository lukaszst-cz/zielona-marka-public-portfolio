# NEXIO ELEKTRO

Wersja demonstracyjna Zielonej Marki, nieoficjalna koncepcja strony hurtowni. Plik `NEXIO_ELEKTRO_PODGLAD_FINAL.html` z Dysku Google, zawierający stronę HTML z osadzonymi stylami i skryptami. To archiwalna wersja demonstracyjna, a nie zweryfikowana identyczna kopia wszystkich wariantów Vercel (`nexio-elektro`, `nexio2`).
