# AUREA SMILE

Wersja demonstracyjna Zielonej Marki, nieoficjalny projekt stomatologiczny. Pełny pojedynczy plik HTML V12 (`AUREA_SMILE_V12_HERO_MENU_2026-11-12.html`) wraz z osadzonymi stylami i treściami, zapisany z Dysku Google. Nie zweryfikowano niezależnego działania wszystkich zewnętrznych odwołań ani identyczności z produkcyjnym Vercel.
