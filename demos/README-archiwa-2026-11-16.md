# Archiwa kodu demonstracji Zielonej Marki

Zapisano 16 listopada 2026. Pliki ZIP zawierają HTML, CSS, JavaScript i zasoby, zgodnie z nazwą paczki. Warianty są koncepcyjne i nie stanowią oficjalnych stron firm. Źródłem są zweryfikowane archiwa właściciela z Dysku Google. Nie każdy ZIP jest identyczny z najnowszym wdrożeniem Vercel; przed zmianą produkcji należy sprawdzić wersje i prawa do obrazów.

- `materivo/source-premium-2026-10-29.zip`: strona Premium z grafikami.
- `materivo/source-ekonomiczny-2026-10-29.zip`: strona Ekonomiczna z grafikami.
- `nexio-elektro/source-dynamic-2026-11-06.zip`: dynamiczne wydanie NEXIO ELEKTRO z PWA.

Nie uruchamiać formularzy jako rzeczywistego mechanizmu obsługi klienta bez konfiguracji.
