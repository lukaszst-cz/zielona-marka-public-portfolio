# MATERIVO Eko i Pro

Dwa warianty demonstracyjne strony centrum budowlanego Zielonej Marki. Strony Eko i Pro mają wspólny przełącznik w `index.html` i kompletny katalog zdjęć w `assets/`.

Strony działają pod adresami:
- https://materivo-eko.vercel.app
- https://materivo-pro.vercel.app

Wersja ekonomiczna zawiera interaktywną gazetkę, a Pro dodatkowo katalog i koszyk zapytań. Projekt oraz ceny są demonstracyjne.

Aktualizacja: 16 listopada 2026. Poprawiono ikony i usunięto znak em dash.
