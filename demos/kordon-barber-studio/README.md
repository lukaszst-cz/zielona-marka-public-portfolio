# KORDON Barber Studio, wersja pokazowa Zielonej Marki

**Status:** zaakceptowane demo, 10.11.2026  
**Hosting aktualnej strony:** Vercel  
**Adres:** https://kordon-barber-studio-zielona-marka.vercel.app/  
**Charakter:** projekt poglądowy, nie oficjalna witryna salonu.

## Zawartość

- `index.html`: kod zaakceptowanej strony z lokalnymi ścieżkami do zasobów.
- `assets/`: 20 plików graficznych z opublikowanej wersji, w tym fotografie 10 produktów.
- `manifest.json`: spis zasobów i źródła archiwum.

Otwórz `index.html` w przeglądarce. Style i skrypty są wbudowane w HTML. Google Fonts są ładowane z zewnętrznej usługi.

## Ograniczenia wersji pokazowej

Koszyk i rezerwacje są demonstracyjne. Brak integracji z Booksy, systemem magazynowym i rzeczywistą płatnością. Ceny i materiały produktowe są przykładowe. Formularz kontaktowy przygotowuje wiadomość w programie pocztowym.

## Zapisana wersja

Wersja po poprawkach: nagłówek „Barbering / z charakterem” w dwóch wierszach; subtelne tło wnętrza w kartach kosmetyków; poprawiony panel Zielonej Marki bez dużych strzałek; usunięte puste białe pola z niepotrzebnego formularza Netlify pod stopką.

Archiwum w GitHub nie zmienia projektu ani wdrożenia Vercel. Pliki są zachowane jako demo portfolio.
